# 音馆

音馆用于管理和播放自己的音乐库。

## 下载

打开[版本与下载](https://github.com/duzhe2007/yinguan-releases/releases)，按你的设备选择安装包。每次发布会列出各平台版本、适用的系统或架构，以及文件校验值。

| 你要安装到哪里 | 选择对应的附件 |
| --- | --- |
| Android 手机或平板 | Android APK |
| Mac | macOS 安装包 |
| Windows | Windows 安装包 |
| Ubuntu | Ubuntu DEB |
| 飞牛 NAS | 飞牛 FPK |
| Docker 主机 | Docker 镜像或离线镜像包 |

## 开始使用

- 在飞牛 NAS 安装 FPK 后，可在应用中心的「应用设置 → 访问权限」为音馆添加歌曲所在的目录。
- 已有音馆后台时，打开客户端并连接该后台。首次搭建后台可按对应版本的飞牛或 Docker 说明安装。
- 更新时，请按发布说明选择同平台的较新版本，保留既有应用数据。
